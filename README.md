# Apex Garage

Offline racing team-manager game (F1/Indy style). Single-page web app: open `index.html` (needs internet once for Three.js from a CDN and fonts).

- `index.html` — built game (what GitHub Pages serves)
- `src/` — sources (`head.html`, `world.js`, `sim.js`, `audio.js`, `game.js`); rebuild with `cd src && python3 build.py && mv index.html ..`
- `brand/` — app icon
